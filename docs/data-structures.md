# Data Structures Used in the Modern Parking Management System

## 1. Introduction

Data structures are used to organize, store, and manage information efficiently. The Modern Parking Management System uses different data structures to support parking slot management, vehicle records, transactions, and database operations.

The main data structures considered for the system are:

1. Arrays/Lists
2. Queues
3. Stacks
4. Hash Tables/Dictionaries
5. Linked Lists
6. Graphs
7. Relational Database Tables
